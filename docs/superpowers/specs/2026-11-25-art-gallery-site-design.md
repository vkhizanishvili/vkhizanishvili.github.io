# Сайт художника: галерея + «Об авторе» + админка — дизайн

Дата: 2026-11-25 · Статус: согласован

## 1. Цель и рамки

**MVP:**

- **Галерея** (главная страница): сетка картин с фильтром по сериям. В карточке — фото, название, цена или статус («продана»), короткая подпись (техника, размер, год). Клик открывает картину крупно, с дополнительными фото и описанием.
- **Об авторе**: фото, биография, необязательные разделы (выставки, образование), контакты.
- **Админка** `/admin`: редактирование картин, серий, страницы «Об авторе» и настроек сайта без программирования.
- **Всё бесплатно**: GitHub (репозиторий, Actions, Pages) и open-source инструменты.

**Не входит в MVP, но заложено:** кнопка «Заказать» → Telegram (уже реализована, выключена в настройках), корзина, данные покупателя, оплата (раздел 8).

Референсы: vlubishkin.ru/originals (серии с описаниями, подпись «размер / техника / цена»), ksugovoruhina.ru (каталог карточками, отметка «нет в наличии»).

## 2. Выбранный подход и альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. Eleventy + Sveltia CMS + GitHub Pages** (выбран) | Готовые HTML-страницы: индексируются Яндексом/Google, красивые превью ссылок в Telegram/VK. Автоматическая оптимизация фото (WebP, несколько размеров) — быстро на телефоне. Нет сервера и подписок | Сборка 1–2 мин после каждого сохранения в админке |
| B. Чистый HTML + JS, читающий JSON | Нет шага сборки | Контент рисуется скриптом — хуже для поисковиков и превью; фото не оптимизируются |
| C. Astro / Next.js | Мощнее для будущего магазина | Избыточно для двух страниц; корзину можно сделать на обычном JS |
| Tilda / WordPress | Привычно | Платный тариф или хостинг |

## 3. Архитектура

```
Редактор ──► /admin (Sveltia CMS в браузере, вход по GitHub-токену)
                 │  «Опубликовать» = коммит в репозиторий (тексты + фото)
                 ▼
            GitHub-репозиторий ──► GitHub Actions: сборка Eleventy,
                                   нарезка изображений, тесты
                                        │
                                        ▼
                                   GitHub Pages: https://<логин>.github.io/<репозиторий>/
```

Стек: Eleventy 3 (шаблоны Nunjucks), `@11ty/eleventy-img`, чистые CSS и JS без фреймворков, Sveltia CMS (с CDN unpkg), тесты на встроенном `node:test`.

### Структура репозитория

```
.github/workflows/deploy.yml   сборка + тесты + публикация на Pages
eleventy.config.js
package.json
src/
  _data/site.json              настройки сайта (редактируются в админке)
  _data/about.json             страница «Об авторе» (редактируется в админке)
  _includes/                   layout, шапка, подвал, карточка, лайтбокс
  _lib/                        чистые функции: цена, статусы, сортировка, ссылки
  content/paintings/*.md       одна картина = один файл (front matter)
  content/series/*.md          серии
  index.njk                    галерея
  about.njk                    об авторе
  admin/index.html, config.yml Sveltia CMS
  assets/css, assets/js        стили, галерея/лайтбокс; assets/js/shop/ — задел
  assets/fonts                 шрифт с кириллицей, хранится локально
  uploads/                     загруженные фото
tests/                         unit- и сборочные тесты
docs/                          дизайн, план, инструкции
```

## 4. Модель контента

**Картина** — `src/content/paintings/<id>.md`, где `id` — короткий латинский идентификатор, который CMS генерирует сама (названия кириллические).

| Поле | Тип | Обяз. | Примечание |
|---|---|---|---|
| title | строка | да | «Утро у реки» |
| image | изображение | да | главное фото |
| photos | изображения (несколько) | нет | детали, в интерьере |
| price | целое, ₽ | нет | пусто → «цена по запросу» |
| status | выбор | да | `available` в наличии · `reserved` забронирована · `sold` продана · `private` в частной коллекции |
| series | связь с «Серией» | нет | |
| technique | строка | нет | «холст, масло» |
| size | строка | нет | «60 × 80 см» или «А3» |
| year | целое | нет | |
| description | текст | нет | показывается в крупном просмотре |
| order | целое | нет | порядок вручную: меньше — выше |
| date | дата | авто | для сортировки «новые сверху» |
| draft | флажок | нет | скрыть с сайта |

Сортировка: сначала по `order` (пустые в конце), затем по `date`, новые сверху.

**Серия** — `src/content/series/<id>.md`: `title`, `description` (необязательно, показывается над сеткой при выбранном фильтре), `order`.

**Об авторе** — `src/_data/about.json`: `photo`, `heading`, `bio` (markdown), `sections[]` (`title` + markdown), `contacts` (`email`, `phone`, `telegram`, `whatsapp`, `instagram`, `vk`, `city`), `links[]` (`label` + `url`). Пустые поля на сайте не выводятся.

**Настройки** — `src/_data/site.json`: `title` (имя художника), `tagline`, `description` (для поисковиков), `url`, `order_button` (`enabled: false`, `label: "Заказать"`, `telegram`, `message` с подстановкой `{title}`).

## 5. Страницы и поведение

**Общее:** светлый минимализм — белый фон, много воздуха, один шрифт без засечек с кириллицей (хранится в репозитории, без Google Fonts), тёмно-серый текст, без декоративных элементов: главное — картины. Шапка: имя художника слева, навигация «Работы / Об авторе» справа. Адаптивность: 1 колонка на телефоне, 2 на планшете, 3–4 на десктопе.

**Галерея:**

- Фильтры-кнопки «Все» плюс серии, в которых есть работы. Фильтрация без перезагрузки; выбранная серия попадает в адрес (`#series-<id>`), так что ссылкой можно поделиться.
- Карточка: фото целиком (без обрезки, `object-fit: contain` в светлой рамке), название, подпись «техника · размер · год», цена «45 000 ₽» либо статус.
- Правила цены: `available` — цена или «цена по запросу»; `reserved` — цена + «забронирована»; `sold` — «продана»; `private` — «в частной коллекции».
- Крупный просмотр (`<dialog>`): большое фото, миниатюры доп. фото, все поля, описание; стрелки и свайп — к соседней картине; Esc закрывает; у каждой картины своя ссылка `#w-<id>`. Кнопка «Заказать» появляется, только если включена в настройках и статус `available`.
- Без JavaScript карточка просто открывает большое фото.

**Об авторе:** на десктопе фото слева, текст справа; ниже разделы и блок контактов (почта → `mailto:`, телефон → `tel:`, Telegram/WhatsApp/соцсети — ссылки).

**SEO:** `<title>`/description, Open Graph (превью ссылок), `sitemap.xml`, `robots.txt`, `lang="ru"`. Админка закрыта от индексации.

## 6. Изображения

- При загрузке в админке Sveltia сама переводит фото в WebP и ограничивает размер до 2400 px — репозиторий не разрастается.
- При сборке `eleventy-img` делает размеры 480/960/1600/2400 в WebP и JPEG; в карточках — `srcset` с ленивой загрузкой.
- Лимиты GitHub: репозиторий до ~1 ГБ, сайт Pages до 1 ГБ, трафик ~100 ГБ/мес. Это тысячи картин.

## 7. Админка

- Sveltia CMS на `/admin/` (open source, преемник Decap/Netlify CMS). Интерфейс на русском — по языку браузера.
- Вход: кнопка «Sign In with Token» + fine-grained токен GitHub с правом `Contents: Read and write` только на этот репозиторий. Создаётся один раз по инструкции; токен хранится в браузере.
- Разделы: «Картины», «Серии», «Страницы и настройки» (Об авторе, Настройки сайта).
- «Опубликовать» = коммит; сайт обновляется через 1–2 минуты.
- Локально (Chrome/Edge) админка умеет работать с папкой проекта напрямую, без GitHub — удобно для проверки.

## 8. Задел под магазин

1. **Кнопка «Заказать» → Telegram** — сделано сейчас, включается флажком в настройках: ссылка `t.me/<ник>?text=…` с названием картины.
2. **Корзина и данные покупателя** — разметка карточек уже содержит `data-id`, `data-title`, `data-price`, `data-status`. Корзина на JS (`localStorage`) в `assets/js/shop/`, страница оформления с формой. Заявка уходит через бесплатную серверную функцию → уведомление в Telegram или на почту.
3. **Оплата** — через провайдера, работающего с самозанятыми/ИП (ЮKassa, Robokassa, CloudPayments и т. п.). Нужны юридический статус, оферта, страница «Оплата и доставка»; комиссия провайдера ~3–4 % — бесплатно не бывает. Статус `sold` ставится в админке или автоматически через GitHub API.

**Важно:** правила GitHub Pages запрещают использовать его как хостинг интернет-магазина. Галерея с ценами — нормально; когда появится корзина с оплатой, ту же сборку нужно перенести на хостинг, где коммерция разрешена (Netlify и т. п., с проверкой доступности в РФ). Код от этого не меняется.

## 9. Тестирование

- **Unit** (`node:test`): форматирование цены, подписи статусов, сортировка, скрытие черновиков, список серий с работами, сборка Telegram-ссылки.
- **Сборка**: сайт собирается; в галерее столько карточек, сколько опубликованных картин; черновик скрыт; кнопки «Заказать» нет при выключенной настройке и есть при включённой (с корректной ссылкой); на «Об авторе» выводятся заполненные контакты; префикс пути для `github.io/<репозиторий>/` применяется.
- **Админка**: `config.yml` парсится; папки коллекций существуют; поля, которые используют шаблоны, есть в конфиге.
- **Вручную в браузере**: десктоп и мобильный вид, фильтр, лайтбокс, загрузка админки.
- Тесты запускаются и в GitHub Actions перед публикацией: сломанная сборка не попадёт на сайт.

## 10. Публикация

Бесплатный аккаунт GitHub → публичный репозиторий (на бесплатном тарифе Pages работает только с публичными) → загрузить код → Settings → Pages → Source: GitHub Actions. Адрес — `https://<логин>.github.io/<репозиторий>/`. Свой домен необязателен: он платный, ~200–1000 ₽ в год, и подключается позже. Пошаговая инструкция — в `docs/`.
