# Оформление сайта в админке — дизайн

Дата: 2026-11-26. Размер: небольшая доработка (настройки, стили, шрифты, админка).

## Зачем

В ближайшее время понадобится менять цвет фона, шрифты и их размер. Это нужно делать самим через админку, без программиста: сохранили — через 1–2 минуты на сайте, как с картинами.

## Решено с заказчиком

- Новый раздел админки «Оформление»: цвет фона, цвет текста, шрифт заголовков, шрифт текста, размер текста.
- Шрифты — **готовый список, хранится на самом сайте** (не Google Fonts). Список одобрен: без засечек — Onest (сейчас), Inter, Manrope, Montserrat, IBM Plex Sans, Raleway; с засечками — PT Serif, Lora, Playfair Display, Cormorant Garamond.
- Остальные оттенки сайт считает из двух цветов сам.
- Размер — одним выбором: «мельче / обычный / крупнее / ещё крупнее», меняется весь сайт пропорционально.

## Не делаем

- Цвета отдельных мест (кнопки, линии, статусы «продана» / «забронирована» остаются своими).
- Размер в пикселях, загрузку своих файлов шрифтов, шрифты из Google.
- Предпросмотр оформления в самой админке (она показывает поля, а не сайт) — вместо него подсказка «изменения появятся на сайте через 1–2 минуты».

## Чего нельзя допустить

- Нечитаемый сайт из-за неудачного сочетания цветов.
- Изменение внешнего вида при выкатке: значения по умолчанию = нынешний вид (белый фон, текст #1b1b1b, Onest везде, «обычный»).
- Загрузку всех десяти шрифтов каждым посетителем.
- Поломку публикации из-за правки в админке (тесты не должны зависеть от выбранного оформления — как уже сделано для содержимого).

## Варианты

- **А. Готовый список шрифтов на сайте — выбран.** Быстро, работает в России без внешних запросов, работает в копии с диска; новый шрифт — только через доработку.
- **Б. Любой шрифт Google Fonts по названию** — гибче, но внешний запрос к Google при каждом посещении, медленнее, данные посетителей уходят за границу, опечатка в названии незаметно ломает шрифт. Не выбран.

## Как устроено (решения Claude)

- **Данные:** `src/_data/theme.json` — `background`, `text` (цвета `#rrggbb`), `heading_font`, `body_font` (идентификатор из списка), `size` (`small` / `normal` / `large` / `xlarge` = 93,75 / 100 / 112,5 / 125 % базового размера).
- **Админка:** в «Страницы и настройки» новый файл «Оформление»: два виджета `color` (с ручным вводом кода), два `select` со списком шрифтов (подписи по-русски с пометкой «с засечками»), `select` размера; подсказка про 1–2 минуты.
- **Стили:** базовый шаблон выводит в `<head>` небольшой блок `:root { … }` с переменными из `theme.json`; оттенки считаются через `color-mix()` из фона и текста: приглушённый текст, линии, подложка под картинами, затемнение за окном картины, фон крестика; кнопки — цвет текста, надпись на них — цвет фона. Жёстко заданные сейчас белые цвета (затемнение, крестик, надписи на кнопках) переводятся на переменные.
- **Шрифты:** все десять пакетов Fontsource (кириллица + латиница; переменные версии, PT Serif — 400 и 700) копируются в сайт, но `@font-face` выводится только для двух выбранных — посетитель скачивает только их. Предзагрузка — для шрифта текста.
- **Защита от нечитаемости:** если контраст фона и текста ниже 3 : 1, сайт берёт вместо выбранного цвета текста чёрный или белый (что читается лучше), а в журнале сборки пишет предупреждение. Подсказка в админке объясняет это.
- **Неверные значения** (пустой цвет, неизвестный шрифт) → значение по умолчанию, без ошибки сборки.

## Оставлено исполнителю

Точные доли `color-mix`, подписи в админке, тесты: чистые функции (проверка значений, контраст, выбор чёрного/белого, CSS-переменные, `@font-face` выбранных шрифтов), сборочные (оформление по умолчанию = нынешний вид; другое оформление попадает в `<head>`; выводятся только выбранные шрифты), админка (поля «Оформления» и список шрифтов совпадают со списком в коде); проверка в браузере на компьютере и телефоне с тёмным фоном и шрифтом с засечками.
