# Инструкция: публикация сайта и работа в админке

Всё, что ниже, бесплатно. Понадобится только аккаунт на GitHub.

## Часть 1. Публикация (один раз, ~20 минут)

### 1. Аккаунт и репозиторий

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатный тариф).
2. Нажмите **New repository** (зелёная кнопка или «+» вверху справа).
3. Название — например `art-site`. Тип — **Public**: на бесплатном тарифе GitHub Pages работает только с публичными репозиториями. Ничего больше не отмечайте и нажмите **Create repository**.

> Публичный репозиторий означает, что файлы сайта видны всем. Для сайта это нормально: всё в нём и так публично. Не храните там ничего личного.

### 2. Впишите свой репозиторий в настройки админки

Уже сделано: в файле `src/admin/config.yml` стоит

```yaml
repo: vkhizanishvili/vkhizanishvili.github.io
```

Если когда-нибудь перенесёте сайт в другой репозиторий — поменяйте эту строку на `логин/название`.

### 3. Загрузите файлы в репозиторий

**Вариант А: командная строка** (нужен установленный [Git](https://git-scm.com)). В папке проекта:

```powershell
git init -b main
git add .
git commit -m "Сайт художника"
git remote add origin https://github.com/ЛОГИН/РЕПОЗИТОРИЙ.git
git push -u origin main
```

При первом `git push` откроется окно входа в GitHub.

**Вариант Б: без командной строки.** Установите бесплатную программу [GitHub Desktop](https://desktop.github.com), выберите *File → Add local repository*, укажите папку проекта и нажмите *Publish repository*. Галочку *Keep this code private* снимите.

### 4. Включите GitHub Pages

В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Затем откройте вкладку **Actions**: там идёт сборка «Публикация сайта». Через 1–2 минуты появится зелёная галочка, и сайт откроется по адресу

```
https://vkhizanishvili.github.io/
```

(Для репозитория с другим названием адрес был бы `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.)

Если сборка красная — откройте её и посмотрите, какой шаг упал. Чаще всего это опечатка в данных; тесты не пустят сломанную версию на сайт, а прежняя продолжит работать.

## Часть 2. Вход в админку

Админка находится по адресу `https://vkhizanishvili.github.io/admin/`.

### Создайте токен (один раз)

Токен — это «ключ», которым админка сохраняет изменения в вашем репозитории.

1. Прямая ссылка: https://github.com/settings/personal-access-tokens/new (войдите в аккаунт сайта).
   Или вручную: GitHub → **ваш аватар** (правый верхний угол) → **Settings** → в самом низу меню слева **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**. Это настройки *аккаунта*: во вкладке Settings репозитория раздела Developer settings нет.
   В окне входа админки есть ссылка, которая открывает эту страницу с уже выбранными правами.
2. **Token name**: «Админка сайта».
3. **Expiration**: например, 1 год — выберите готовый вариант в списке или дату в календарике **не дальше года**: более далёкую дату GitHub может не принять (тогда пишет «never expire», а кнопка создания не срабатывает). Когда срок истечёт, создайте новый токен так же.
4. **Repository access → Only select repositories** → выберите репозиторий сайта.
5. **Permissions → Repository permissions → Contents → Read and write**.
6. Нажмите **Generate token** и скопируйте токен: GitHub показывает его один раз.
7. В админке нажмите **«Войти с помощью токена доступа»** и вставьте токен.

Браузер запомнит вход. На чужом компьютере после работы выйдите из админки (меню профиля → «Выйти»). Если токен мог попасть в чужие руки — удалите его на той же странице GitHub и создайте новый.

## Часть 3. Работа с контентом

Каждое сохранение в админке — это изменение в репозитории. **Сайт обновляется через 1–2 минуты**; ход сборки виден во вкладке Actions.

| Задача | Где в админке |
|---|---|
| Добавить картину | **Картины → Создать**: название, главное фото, цена, статус. Остальное по желанию |
| Отметить «продана» | Открыть картину → **Статус: Продана** → Сохранить. Цена скроется |
| Временно скрыть картину | Флажок **«Скрыть с сайта»** |
| Изменить порядок | Поле **«Порядок»**: 1, 2, 3… — эти работы встанут первыми. Без числа — по дате, новые сверху |
| Серии (фильтры над галереей) | **Серии → Создать**, затем выбрать серию в картине. Серия без картин на сайте не видна |
| Текст «Об авторе», фото, контакты | **Страницы и настройки → Об авторе**. Пустые контакты не показываются |
| Имя, заголовок, описание для поисковиков | **Страницы и настройки → Настройки сайта** |
| Включить кнопку «Заказать» | **Настройки сайта → Кнопка «Заказать»** → «Показывать кнопку» + ваш Telegram. Кнопка появится у картин со статусом «В наличии» и откроет чат с готовым сообщением |

**Фото.** Загружайте как есть (JPEG, PNG, с телефона). Админка уменьшит фото до 2400 px и переведёт в WebP, а сайт нарежет размеры для телефонов и компьютеров. Совет: снимайте при дневном свете, ровно, обрезайте по краю картины.

### Как убрать демо-контент

Имя и подпись в шапке уже настоящие, разделов и контактов на странице «Об авторе» пока нет. Остальное — заглушки: 8 демо-картин (плюс черновик «Набросок»), 4 серии, фото автора и биография. Замените их в админке в любом порядке — можно, например, сначала удалить все демо-картины: сайт покажет «Скоро здесь появятся работы» и продолжит обновляться.

1. **Картины**: удалите демо-записи (откройте → меню «⋯» → Удалить) или переделайте их в свои.
2. **Серии**: удалите или переименуйте.
3. **Страницы и настройки**: впишите биографию и контакты, загрузите фото автора и картинку для превью ссылок.
4. Демо-изображения лежат в папке `uploads/demo` (раздел медиафайлов в админке) — их можно удалить, когда ни одна запись на них не ссылается.

## Часть 4. Дополнительно

### Форма «Связаться с автором»

В окне каждой картины можно показать кнопку «Связаться с автором», а на странице «Об авторе» — форму «Написать мне»: посетитель заполняет имя, телефон или почту и сообщение, а вам приходит письмо на почту и сигнал в Telegram. Пока форма не настроена, её на сайте нет. Как включить — пошагово в [docs/contact-form-setup.md](contact-form-setup.md) (около 30 минут, понадобятся Яндекс Почта, Telegram и Яндекс Облако).

### Свой домен (необязательно, платно ~200–1000 ₽/год)

Купите домен у регистратора → в репозитории **Settings → Pages → Custom domain** → следуйте подсказкам GitHub по настройке DNS. Затем в админке впишите адрес в **Настройки сайта → Адрес сайта** (например, `https://ivanova-art.ru`).

### Посмотреть сайт на своём компьютере

Нужен [Node.js](https://nodejs.org) (версия LTS). В папке проекта:

```powershell
npm install
```

```powershell
npm start
```

Сайт откроется на `http://localhost:8080`. Админка локально: `http://localhost:8080/admin/index.html` → «Работать с локальным репозиторием» (только Chrome или Edge; папка проекта должна быть Git-репозиторием). Изменения сохраняются прямо в файлы, на GitHub их нужно отправить самостоятельно.

### Лимиты бесплатного GitHub

- Сайт — до 1 ГБ, трафик — около 100 ГБ в месяц. Этого хватит на сотни картин и тысячи посетителей.
- GitHub Pages нельзя использовать как хостинг интернет-магазина. Галерея с ценами — можно; про магазин см. `docs/future-shop.md`.
