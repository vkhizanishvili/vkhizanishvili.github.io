# Как включить форму «Связаться с автором»

Форма в окне картины отправляет сообщение посетителя вам на почту и присылает короткий сигнал в Telegram. Сайт сам отправлять письма не умеет, поэтому сообщения принимает маленькая программа в Яндекс Облаке. Её настройка — один раз, примерно 30 минут. Программировать не нужно.

Что получится:

- **на почту** — письмо с именем, телефоном или почтой посетителя, текстом и ссылкой на картину;
- **в Telegram** — «Новое сообщение о картине „…“. Подробности на почте.» (без имени и телефона: серверы Telegram за границей);
- если Яндекс Облако недоступно, посетитель увидит ваш адрес почты и кнопку «Открыть почту» — сообщение не пропадёт.

Понадобятся: Яндекс ID с Яндекс Почтой, Telegram, банковская карта (для Яндекс Облака; при таком объёме платить не придётся — первый миллион вызовов в месяц бесплатный).

---

## Шаг 1. Почта: пароль приложения

Программа будет отправлять письма с вашего ящика Яндекс Почты на него же. Для этого нужен отдельный «пароль приложения» — не ваш основной пароль.

1. Откройте Яндекс Почту → **Настройки** (шестерёнка) → **Все настройки** → **Почтовые программы**. Включите **«С сервера imap.yandex.ru по протоколу IMAP»** и способ авторизации **«Пароли приложений и OAuth-токены»**. Сохраните.
2. Откройте [id.yandex.ru](https://id.yandex.ru) → **Безопасность** → **Пароли приложений** → **Почта** → **Создать**. Назовите, например, «Форма на сайте».
3. Скопируйте показанный пароль и сохраните до шага 3 (второй раз его не покажут).

## Шаг 2. Telegram: бот и номер чата

1. В Telegram найдите **@BotFather**, нажмите **Start**, отправьте `/newbot`.
2. Придумайте имя (например, «Сайт Валерии») и адрес бота — латиницей, в конце `bot` (например, `valeria_gallery_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Сохраните его до шага 3 и никому не показывайте.
4. Откройте своего нового бота (ссылка есть в сообщении BotFather) и нажмите **Start** — иначе бот не сможет вам писать.
5. Узнайте номер своего чата: откройте в браузере
   `https://api.telegram.org/bot<токен>/getUpdates` (вместо `<токен>` — ваш токен целиком).
   Найдите `"chat":{"id":` и число после него, например `123456789`. Это **номер чата**.
   Если видите `"result":[]` — напишите боту любое сообщение и обновите страницу.

Telegram можно пропустить: тогда будут приходить только письма.

## Шаг 3. Яндекс Облако: программа-пересыльщик

### Архив программы

Готовый архив — файл `offline/contact-function.zip` в папке проекта. Если его нет, его создаёт команда `npm run contact-function` (или попросите Claude).

### Создать функцию

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите своим Яндекс ID.
2. Если облако просит **платёжный аккаунт** — создайте его как физическое лицо и привяжите карту.
3. В каталоге (обычно `default`) выберите сервис **Cloud Functions** → **Создать функцию**. Имя — например, `contact-form`.
4. В редакторе функции:
   - **Среда выполнения** — Node.js, самая новая из предложенных;
   - **Способ** — ZIP-архив, загрузите `contact-function.zip`;
   - **Точка входа** — `index.handler`;
   - **Таймаут** — `10` секунд; **Память** — `128 МБ`;
   - **Переменные окружения** — добавьте по одной:

| Ключ | Значение |
|---|---|
| `ALLOWED_ORIGINS` | адрес сайта **без** пути и без `/` в конце: `https://vkhizanishvili.github.io` (если подключите свой домен — `https://ваш-домен.ru`). Чтобы проверять с компьютера, допишите через запятую `http://localhost:8080` |
| `MAIL_USER` | ваш адрес Яндекс Почты, например `v.art@yandex.ru` |
| `MAIL_PASSWORD` | пароль приложения из шага 1 |
| `MAIL_TO` | *необязательно:* другой адрес, куда слать письма (по умолчанию — `MAIL_USER`) |
| `TELEGRAM_BOT_TOKEN` | токен бота из шага 2 |
| `TELEGRAM_CHAT_ID` | номер чата из шага 2 |

5. Нажмите **Сохранить изменения** (создастся версия функции).
6. На странице функции включите **Публичная функция** — иначе сайт не сможет до неё достучаться.
7. Скопируйте **ссылку для вызова** — вида `https://functions.yandexcloud.net/d4e...`.

## Шаг 4. Админка сайта

1. Откройте админку сайта → **Страницы и настройки** → **Настройки сайта** → **Форма связи**.
2. Включите **«Показывать кнопку „Связаться с автором“»**.
3. В **«Адрес функции»** вставьте ссылку из шага 3.
4. В **«Почта для запасного пути»** — ваш адрес (его увидят, только если отправка не удалась).
5. Сохраните. Через 1–2 минуты сайт обновится, в окне каждой картины появится кнопка, а в подвале — ссылка на политику.

Пока хоть одно из полей пустое, кнопки на сайте не будет.

## Шаг 5. Проверка

1. Откройте опубликованный сайт (лучше с телефона), откройте картину → **Связаться с автором**.
2. Заполните форму своими данными, подождите пару секунд и нажмите **Отправить**.
3. Должно появиться «Спасибо!…», через минуту — письмо на почте и сигнал в Telegram.

**Если письмо не пришло:**

- в Яндекс Облаке откройте функцию → **Логи**: там видно, что пошло не так (строки с `[contact] Почта:` или `[contact] Telegram:`);
- проверьте пароль приложения и `MAIL_USER` (адрес целиком, с `@yandex.ru`) и что в настройках Почты включён доступ по IMAP (шаг 1);
- если сайт пишет «Не получилось отправить» сразу — проверьте `ALLOWED_ORIGINS`: адрес должен точно совпадать с тем, что в адресной строке до первого `/` после домена, и функция должна быть **публичной**.

Если изменили переменные окружения — сохраните новую версию функции.

## Шаг 6. Юридическое

Форма собирает имя и телефон или почту — это персональные данные.

1. **Политика обработки персональных данных** — в админке: **Страницы и настройки** → **Политика обработки персональных данных**. Заполните всё в [квадратных скобках], удалите строку «Черновик…» и покажите текст юристу.
2. Уточните у юриста, нужно ли вам **уведомить Роскомнадзор** как оператору персональных данных.
3. Данные посетителей собираются в России (Яндекс Облако, Яндекс Почта) — с 1 июля 2025 года это обязательное требование для сбора через интернет. Не пересылайте письма из формы на зарубежные почтовые сервисы.
